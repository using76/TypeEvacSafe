전제(이틀 실측): 판단은 규칙 프롬프트 + 27B 생각 모드로 이미 29/30, TypeSafe 27/30 → 문제는 속도(25 s/판단). 이동 정책이 못 배운 원인은 환경 결함(출구선 건너뜀·항법)이었고 수정됨(eb836fb). 물리 반사는 학습 대상이 아니다.

## 2층 판단층(피난 전용 Jev, 결정 단위)

### head
| head | 옵션 | 가드 |
|---|---|---|

### 신호 3단계
(a) **증류**: 규칙 매크로로 굴리며 결정점마다 상황 텍스트 + 교사(27B think / TypeSafe) 옵션 확률 저장 → 학생(Qwen3.5-4B 또는 1.7B, LoRA) 글자 즉답 SFT(옵션별 KL). 옵션 순서·규칙 환언 증강. 목표: 저작 벤치 ≥27/30, <0.1 s/판단. 시작 규모 1.6만(케이스 100 × 32명 × 결정점 5).
(b) **결과 보정**: 결정점마다 후보 전수를 1층 정책으로 벡터 롤아웃 → R_dec → advantage-weighted CE / DPO.

| head | R_dec |
|---|---|
| mode / target_exit | 다음 결정까지 1층 보상 합 + 종결(탈출 +100, 쓰러짐 −100, 사망 −150) − 출구 변경 5(대기 차 ≥5 s 면제) |
| rescue_target | 구조 완료 +100, 확보 후 피구조자 사망 −100, 자기 FED −20×Δ, 무의미 진입 −10 |
| rescue_feasible / survive | 실제 0/1 분류(Brier) |
| start_now | 출발~탈출 FED −20×, 병목 대기 −0.1/s, 늦은 출발 쓰러짐 −100 |
| aset_left | 실제값 Huber |
| 보호자 | 피보호자 탈출 +60 / 사망 −100, 분리 −0.05/s, 혼자 먼저 ×0.5 |

(c) **보정**: 온도 스케일링 + ECE.
1층·2층은 번갈아 갱신(동시 갱신 금지).
